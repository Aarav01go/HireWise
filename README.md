# 🏢 HireWise

**HireWise** is a lightweight, AI-driven Human Resource Management System (HRMS). Built over a 7-day sprint, this project demonstrates how modern AI features can be integrated into traditional HR workflows to automate tedious tasks and provide intelligent insights.

---

## ✨ Features

### 1. Core HR Base System
* **Role-Based Access Control (RBAC):** Secure login portals tailored for HR Managers and standard Employees.
* **Employee Directory:** View and manage company headcount and employee profiles.
* **Leave Management:** Employees can apply for time off, while HR can review, approve, and track pending requests in a centralized inbox. Automatic leave balance deduction upon approval.

### 2. Digital AI Layer
* **🤖 AI HR Assistant (Chatbot):** A custom Chatbot powered by Google Gemini and RAG (Retrieval-Augmented Generation). It reads the company policy document and the logged-in employee's database records to answer questions like *"What is the notice period?"* or *"How many leaves do I have?"*
* **🧠 AI Resume Screening:** HR can upload multiple candidate resumes (PDFs) alongside a Job Description. Gemini instantly reads the PDFs, scores the candidates from 0 to 100, and writes a short justification for the score.
* **🔮 Attrition Prediction:** A built-in Machine Learning model trained on the IBM HR Analytics Kaggle Dataset. HR can enter employee metrics (Age, Income, Job Satisfaction, Overtime) to get an instant % probability of the employee resigning.

---

## 🛠️ Tech Stack
* **Frontend:** Streamlit (Python)
* **Database:** SQLite
* **AI & LLM:** Google Gemini API (`gemini-2.5-flash`)
* **Machine Learning:** Scikit-Learn (Random Forest Classifier), Pandas, NumPy
* **Utilities:** `pypdf` (for parsing resumes), `python-dotenv` (for API key management)

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Aarav01go/HireWise.git
   cd HireWise
   ```

2. **Set up the virtual environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows use: venv\Scripts\activate
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Configure your API Key:**
   Create a `.env` file in the root directory and add your Google Gemini API key:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

5. **Initialize the Database:**
   *(Run this once to create `hrms.db` and insert dummy data)*
   ```bash
   python setup_db.py
   ```

6. **Start the Application:**
   ```bash
   streamlit run app.py
   ```
